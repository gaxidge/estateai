# EstateAI — Yapay Zekâ Destekli Emlak Yönetim SaaS Platformu

Emlak ofisleri ve bağımsız gayrimenkul danışmanları için yapay zekâ destekli, modern ve abonelik modeliyle çalışan SaaS platformu.

## Modüller

- **Genel Bakış (`/`)**: Ofis performans özeti, KPI kartları, 6 aylık portföy grafiği, müşteri dönüşüm hunisi ve yaklaşan randevular.
- **Portföy Yönetimi (`/portfoyler`)**: 8 gayrimenkul kategorisi (Daire, Müstakil Ev, Villa, Arsa, Tarla, İş Yeri, Dükkan, Ticari Gayrimenkul), gelişmiş filtreleme, ilan ekleme/düzenleme/silme.
- **Müşteriler & CRM (`/crm`)**: Potansiyel, Aktif, Görüşme Aşamasında ve Tamamlandı durumlarıyla Kanban pano ve tablo görünümü, müşteri ilgi skoru ve uygun ilan eşleştirmesi.
- **AI Asistan (`/ai-asistan`)**: Doğal Türkçe konuşan WhatsApp & Web asistanı, müşteri ihtiyaç özeti, sıfır halüsinasyon koruması ve danışmana devir.
- **Randevular (`/randevular`)**: Haftalık yer gösterme takvimi, müşteri-ilan eşleşmesi ve otomatik WhatsApp hatırlatmaları.
- **Otomatik İşlemler (`/otomasyonlar`)**: Arka planda çalışan otomatik müşteri kaydı, ilan-müşteri eşleştirme, randevu hatırlatma ve gün sonu özeti görevleri.
- **Ayarlar (`/ayarlar`)**: Ofis bilgileri, ekip yönetimi, AI asistan kuralları, WhatsApp bağlantısı, bildirimler ve abonelik paketleri.

## Kurulum ve Çalıştırma

```bash
cd frontend
npm install
npm run dev
```
